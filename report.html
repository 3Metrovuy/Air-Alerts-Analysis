Limitations

  • Volunteer data means "eTryvoga reported an alert", not the official siren system; the two disagree in the west (Volyn, Lviv).
  • Inputs are alert history, the calendar and (if chosen above) weather forecasts. No real-time launch signals (bomber take-offs, drone groups), so the model cannot see a specific attack coming; its skill comes from activity patterns.
  • The >12 h rule uses hindsight (an alert's length is known only after it ends). It only removes rows; it never feeds a value into a feature.
  • The label is "any alert in this hour", so a 1-minute alert and a 6-hour attack count the same.

Leakage check: python test_leakage.py rebuilds every feature from data cut at a point in time and asserts that nothing before the cut changes.
